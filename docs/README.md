# Documentation

Laravel Ticket is a multi-department service desk that runs inside an existing Laravel application. These guides describe the product as it ships.

| Guide | Who it is for |
|---|---|
| [Admin guide](admin-guide.md) | People who install the package, set configuration, and run departments, mail, sign-in, and privacy. |
| [User guide](user-guide.md) | Requesters, agents, and managers who use the desk and the portal. |

The [README](../README.md) keeps the short install steps and the original ticket model API. The admin guide is the reference for every configuration key and operational feature.
